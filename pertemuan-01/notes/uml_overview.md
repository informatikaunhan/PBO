# UML Overview untuk PBO301

- **Class Diagram:** struktur type, atribut, operasi, dan relasi.
- **Object Diagram:** snapshot instance konkret dan nilai state.
- **Sequence Diagram:** urutan message antar-participant dari waktu ke waktu.
- **Use Case Diagram:** tujuan actor terhadap boundary sistem.

UML adalah alat komunikasi desain, bukan pengganti source code.
