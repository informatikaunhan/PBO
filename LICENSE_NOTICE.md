# Catatan lisensi dan atribusi

Bahan ini disiapkan untuk pembelajaran **Pemrograman Berorientasi Obyek (PBO301)** di Universitas Pertahanan Republik Indonesia. Ketentuan penggunaan yang terdapat pada paket sumber dan masing-masing modul tetap berlaku. Publikasi di GitHub tidak dengan sendirinya memberikan lisensi open-source atau izin penggunaan ulang atas seluruh materi, logo, maupun aset pihak ketiga. Hubungi pemegang hak terkait untuk izin penggunaan di luar ketentuan tersebut.
