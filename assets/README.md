# Aset bersama PBO301

Aset visual yang digunakan oleh seluruh modul disimpan satu kali di folder ini, bukan disalin ke setiap pertemuan.

- `logo_unhan.png` — logo Universitas Pertahanan Republik Indonesia, berasal dari logo yang diberikan dosen. Versi PNG transparan dioptimalkan untuk tampilan README GitHub.

Dari `PertemuanNN/Belajar_Mandiri.md`, gunakan:

```markdown
![Logo Universitas Pertahanan Republik Indonesia](../assets/logo_unhan.png)
```

Dari README di root repositori, gunakan `assets/logo_unhan.png`. Jika ada modul yang lebih dalam, sesuaikan jumlah `../` dengan posisi file. Jangan gunakan path lokal dari komputer pembuat materi.
