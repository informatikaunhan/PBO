# Concepts

- Function template = family of functions.
- Class template = family of types.
- Deduction memilih template argument dari call bila konsisten.
- Non-type parameter membawa nilai compile-time, misalnya kapasitas.
- Instantiation membentuk specialization konkret saat dipakai.
- Definition template perlu terlihat pada titik instantiation; header-only adalah pola termudah.
- Requirement terhadap T muncul dari ekspresi yang dipakai template.
