# Pemrograman Berorientasi Objek (PBO301)

Repositori bahan pembelajaran **Pemrograman Berorientasi Objek (PBO301)**, Program Studi Informatika, Fakultas Teknik dan Teknologi Pertahanan, Universitas Pertahanan Republik Indonesia.

## Struktur perkuliahan

- Pertemuan 01 — Pengantar OOP, C++ Modern, dan UML
- Pertemuan 02 — Class, Object, dan Class Diagram
- Pertemuan 03 — Constructor, Destructor, dan Copy Semantics
- Pertemuan 04 — Encapsulation, Access Control, dan Visibility di UML
- Pertemuan 05 — Relasi Antar Obyek: Association, Aggregation, Composition + Object Diagram
- Pertemuan 06 — Inheritance dan UML Generalization
- Pertemuan 07 — Polymorphism dan Virtual Functions
- Pertemuan 08 — UTS
- Pertemuan 09 — Abstraction Bagian 1: Abstract Class dan Pure Virtual Function
- Pertemuan 10 — Abstraction Bagian 2: Interface, Realization, dan Desain Polimorfik
- Pertemuan 11 — Operator Overloading
- Pertemuan 12 — Templates Bagian 1: Function Template dan Class Template
- Pertemuan 13 — Templates Bagian 2: Specialization, STL, dan Generic Container
- Pertemuan 14 — Exception Handling Lanjut dan Exception Safety
- Pertemuan 15 — Interaksi Obyek: Sequence Diagram, Use Case, dan Studi Kasus Terintegrasi
- Pertemuan 16 — UAS

## Isi repositori

Folder pertemuan reguler berisi **bahan belajar mandiri GitHub** yang telah diaudit dan dinormalisasi. Pertemuan 8 dan 16 diberi penanda UTS/UAS. Source code menggunakan **C++17** dengan baseline `-std=c++17 -Wall -Wextra -pedantic`.

## Standar visual

Paket pembelajaran telah diaudit menggunakan **PBO301 Style Guide v1.2**: dokumen A4 margin 18 mm, Noto Sans/Noto Sans Mono, palet navy–marun–emas, identitas UNHAN, dan slide 16:9 dengan teks minimum 18 pt.
