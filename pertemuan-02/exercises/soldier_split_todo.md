# Checkpoint 2 - Split Header/Source

1. Pindahkan declaration `Soldier` ke `include/Soldier.h`.
2. Tambahkan include guard unik.
3. Pindahkan definition method non-inline ke `src/Soldier.cpp`.
4. Gunakan `Soldier::` pada definition.
5. Buat `src/main.cpp` sebagai pemakai class.
6. Build dengan `-std=c++17 -Wall -Wextra -pedantic`.
