# PBO301 Source Repository Audit

Struktur ini dibuat mengikuti pola repositori `informatikaunhan/DDP`: README per pertemuan menjadi titik masuk, dan setiap file yang diperintahkan untuk dibaca/dikerjakan tersedia sebagai file nyata di folder pertemuan.

## Contoh Pertemuan 06

- `README.md`
- `notes/inheritance_vs_composition.md`
- `include/MilitaryUnit.h`
- `starter/military_unit_starter.cpp`
- `exercises/access_hiding_lab.cpp`
- `exercises/diamond_lab.cpp`
- `src/MilitaryUnit.cpp`
- `tests/test_inheritance.cpp`
- `uml/military_hierarchy.puml`
- `uml/amphibious_diamond.puml`

## Shared asset
