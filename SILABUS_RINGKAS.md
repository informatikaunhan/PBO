# Ringkasan Silabus PBO301

Dokumen ini adalah ringkasan navigasi dari silabus aktif PBO301 yang digunakan untuk penyusunan paket pembelajaran.

## Identitas

- Mata kuliah: **Pemrograman Berorientasi Obyek**
- Kode: **PBO301**
- Bobot: **3 SKS (2 teori + 1 praktikum)**
- Semester: **3**
- Bahasa: **C++17**
- Pertemuan: **16** (P8 UTS, P16 UAS)
- Belajar mandiri: **420 menit/minggu**

## Peta Pertemuan

| P | Topik | Sub-CPMK utama |
|---:|---|---|
| 1 | Pengantar OOP, C++ Modern, Pengenalan UML | 1.1, 1.2 |
| 2 | Class, Object, dan Class Diagram | 2.1, 4.1 |
| 3 | Constructor, Destructor, dan Copy Semantics | 2.2 |
| 4 | Encapsulation, Access Control, Visibility UML | 2.3, 4.1 |
| 5 | Association, Aggregation, Composition, Object Diagram | 3.1, 4.1, 4.2 |
| 6 | Inheritance dan UML Generalization | 2.4, 4.1 |
| 7 | Polymorphism dan Virtual Functions | 2.5 |
| 8 | **UTS** | P1-P7 |
| 9 | Abstraction 1 - Abstract Class dan Pure Virtual Function | 2.6, 4.1 |
| 10 | Abstraction 2 - Interface, Realization, Desain Polimorfik | 2.7, 4.1 |
| 11 | Operator Overloading | 2.8 |
| 12 | Templates 1 - Function Template dan Class Template | 5.1 |
| 13 | Templates 2 - Specialization, STL, Generic Container | 5.2 |
| 14 | Exception Handling Lanjut dan Exception Safety | 6.1, 4.1 |
| 15 | Sequence Diagram, Use Case, Studi Kasus Terintegrasi | 4.3, 4.4, 7.1 |
| 16 | **UAS** | P1-P15, penekanan P9-P15 |
