# Copy-and-Swap (Pengayaan)

Copy-and-swap membuat copy temporary terlebih dahulu, menukar state dengan target, kemudian temporary membersihkan state lama saat keluar scope. Kelebihannya adalah kode assignment ringkas dan strong exception safety bila copy dan swap memiliki properti yang sesuai.

Pertemuan 3 tetap mewajibkan mahasiswa memahami self-assignment dan assignment eksplisit sebelum memakai idiom ini.
