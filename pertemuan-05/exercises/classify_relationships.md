# Classify Relationships

Untuk setiap skenario, tulis association / aggregation / composition dan jelaskan lifetime.

1. MissionPlanner -> MapService hanya selama method call.
2. Team -> Operator dari personnel registry.
3. Vehicle -> Engine yang dibuat bersama Vehicle.
4. Report -> Page yang hanya ada di dalam Report.
5. Dashboard -> Sensor API remote.
6. Course -> Student dari academic registry.
7. Tree -> Node internal.
8. Playlist -> Song dari media library.
